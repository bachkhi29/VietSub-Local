LocalBachSub

Nhận diện lời nói, dịch ngữ cảnh tự nhiên, chỉnh sửa đối chiếu song song và xuất MP4 ngay trên máy.

Windows 10/11Hỗ trợ GPU & CPUChạy cục bộ · Không tốn phí API

1Giải nén thư mục

Nếu tải bằng file ZIP, nhấp phải → Extract All / Giải nén tất cả ra thư mục riêng trước khi mở các file .bat.

2Cài Python và Ollama

  • Python 3.11 hoặc 3.12 (64-bit): tích chọn Add python.exe to PATH khi cài.
  • Ollama cho Windows: cài đặt để chạy mô hình dịch ngay trên máy.

3Chạy cài đặt lần đầu

Nhấp đúp 1_CAI_DAT.bat. Script sẽ tự tạo môi trường .venv, cài thư viện nhận diện và tải mô hình dịch qwen3:4b.

4Sử dụng trong 2 bước

Chạy 2_MO_TOOL.bat (tool tự bật ngầm Ollama nếu đang tắt và mở trình duyệt):

  1. Tab 1 · Dịch & Biên tập đối chiếu: thả video hoặc file SRT (hỗ trợ cả SRT gốc và SRT song ngữ) → bấm Tạo / Nhập phụ đề → bấm Dịch các câu còn trống. Khung video bên trái và bảng phụ đề bên phải nằm ngang hàng để vừa xem vừa sửa trực tiếp.
  2. Tab 2 · Thiết kế chữ & Xem / Xuất Video: chọn bộ màu nhanh, khung hình TikTok 9:16 hoặc giữ khung gốc, gom gọn chữ. Bấm Xem thử 30s hoặc Xuất & Xem toàn bộ MP4 để xem trực tiếp video hoàn chỉnh trên giao diện rồi bấm Tải về MP4.

Dừng tool: nhấn Ctrl+C trong cửa sổ Terminal. Mọi công việc đã lưu nằm trong thư mục output/.
