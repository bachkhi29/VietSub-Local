Nhận diện, dịch, sửa phụ đề và xuất MP4 đã dán chữ ngay trên máy.

Windows 11RTX 3050 · 6 GBKhông cần API trả phí

Đã có bản cũ?

Giải nén gói cập nhật → chạy 0_CAP_NHAT_TU_DONG.bat → chọn thư mục VietSub-Local cũ chứa 2_MO_TOOL.bat. Script sẽ chép mã mới, cài phần bổ sung và mở app. Giữ nguyên các dự án đã lưu. Xem hướng dẫn chi tiết.

1Giải nén toàn bộ

Nhấp phải file ZIP → Extract All / Giải nén tất cả. Đặt thư mục ở nơi dễ tìm, chẳng hạn D:\VietSub-Local.

Không mở file BAT trực tiếp bên trong ZIP. Phải giải nén trước.

2Cài hai ứng dụng nền

  • Python 3.12 — trang tải chính thức: kéo xuống Files → Windows installer (64-bit). Bật Add python.exe to PATH và giữ Python Launcher. Nếu đã có Python 3.11/3.12 x64 thì bỏ qua.
  • Ollama cho Windows — trang tải chính thức: cài rồi mở ứng dụng. Tool sử dụng mô hình chạy trên máy; không cần mua gói cloud.

3Chạy bộ cài

Nhấp đúp 1_CAI_DAT.bat và chờ. Script tạo môi trường Python riêng, cài thư viện GPU, rồi tải mô hình dịch.

Lần đầu cần Internet và tải vài GB. Để trống khoảng 15–20 GB trở lên, cộng thêm dung lượng video. Nếu có lỗi, giữ cửa sổ và chụp phần lỗi để kiểm tra.

4Mở và thử clip ngắn

Chạy 2_MO_TOOL.bat. Trình duyệt tự mở; giữ cửa sổ Terminal trong lúc sử dụng.

  1. Tab 1: chọn video 3–5 phút, ngôn ngữ gốc và đích → bấm Tạo phụ đề gốc → Dịch.
  2. Tab 2: sửa từng câu và tải SRT nếu muốn.
  3. Tab 3: chọn khung và kiểu chữ, kéo mốc xem hoặc chuyển câu để thấy phụ đề trên hình video ngay bên cạnh. Chỉnh độ trễ nếu chữ sớm hoặc muộn; chỉ dựng thử MP4 30 giây khi cần kiểm tra chuyển động rồi xuất toàn bộ.

Lần nhận diện đầu còn phải tải mô hình Whisper. Nếu chưa có video, thử nhập file SRT có sẵn trong thư mục examples.

Ông nhận được gì?

File .en.srt, .vi.srt, .vi-en.srt, bản .ass, .vtt và một ZIP chứa các phụ đề. Có thể thử 30 giây và xuất MP4 đã dán chữ với vài lựa chọn kiểu chữ. Công việc được lưu trong output để mở lại.

AI có thể nghe và dịch sai; hãy rà lại câu chữ trước khi xuất bản.

Hướng dẫn đầy đủ và xử lý lỗi nằm trong README.md (có thể mở bằng Notepad).

Dừng tool: Ctrl+C trong Terminal; nếu hỏi Terminate batch job thì nhấn Y. Những thay đổi đang gõ trong bảng cần bấm Lưu trước khi thoát.
